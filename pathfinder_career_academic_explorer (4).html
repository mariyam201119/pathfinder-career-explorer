Project Overview & Details

School Project Presentation

Project Objective

PathFinder: Career & Academic Explorer is built as a complete single-page web application designed to help students navigate post-education choices. It bridges both modern non-academic fields (Game Dev, UI/UX, Ethical Hacking) and traditional academic streams (Science PCM/PCB, Commerce, Arts) with interactive exploration tools and a customized quiz.

Technologies Used

  • • HTML5 Semantic Markup
  • • Tailwind CSS for Styling & Responsive Design
  • • Vanilla JavaScript for Dynamic State & Filtering
  • • Canvas Confetti & FontAwesome Icons

Key Features

  • • Dual Explorer Tabs (Modern vs Academic)
  • • Interactive modal popups with detailed skill tags
  • • 6-question step-by-step quiz with score breakdown
  • • Future-proof skills guide
