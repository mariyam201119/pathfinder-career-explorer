# 🚀 PathFinder: Career & Academic Explorer

PathFinder is an interactive single-page web application designed to help students discover, compare, and evaluate modern tech career pathways alongside traditional academic streams using an intuitive UI and a dynamic diagnostic quiz.

## ✨ Key Features

- **Deep Cosmic Aesthetics:** Designed with a space-themed visual interface featuring smooth ambient glowing gradients.
- **Streamlined Navigation:** Multi-tab layout built without search bar clutter for an intuitive browsing experience.
- **Interactive Career Matcher Quiz:** A 6-question assessment offering instant score evaluation and customized stream recommendations.
- **Modern Tech Pathways:** Dedicated guides for fields such as Game Development, UI/UX Design, Cybersecurity, Digital Media, and Robotics.
- **Traditional Academic Streams:** In-depth overviews of foundational study streams including Science (PCM/PCB), Commerce, Arts, Engineering, Medicine, and Law.
- **Cross-Platform Responsive Layout:** Optimized using standard anchor targets (`#tab-...`) for seamless navigation on mobile devices, tablets, and laptops.
